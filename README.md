## Аннотация
Данный проект представляет собой разработку консольного приложения для проведения школьного тестирования с использованием языка программирования Python и реляционной базы данных SQLite. Проект создан в рамках индивидуального проекта по информатике и демонстрирует практическое применение знаний о базах данных, SQL-запросах и объектно-ориентированном программировании.


## Актуальность
В условиях цифровизации образования возрастает потребность в легких и надежных инструментах для автоматизации проверки знаний. Использование полноценных серверных СУБД (например, PostgreSQL или MySQL) для небольших школьных задач часто избыточно. SQLite является идеальным решением: она не требует отдельной установки сервера, хранит данные в одном файле и при этом поддерживает полный набор возможностей SQL, что делает её отличным полигоном для обучения и создания прототипов.


## Цель проекта
Изучить принципы работы с реляционными базами данных и разработать функциональное приложение для организации и проведения школьного тестирования, позволяющее хранить данные об учениках, учебных темах, вопросах и автоматически проверять ответы.


## Задачи проекта
1. Изучить теоретические основы баз данных, виды СУБД и технические особенности SQLite.
2. Спроектировать структуру базы данных: определить необходимые таблицы (`Students`, `Themes`, `Questions`, `Answers`) и связи между ними.
3. Освоить базовые основы языка SQL для создания таблиц, добавления, изменения и выборки данных.
4. Реализовать программный интерфейс на Python для взаимодействия с БД, применив объектно-ориентированный подход (модули `my_database.py` и `my_models.py`).
5. Разработать логику консольного приложения (`main.py`) для пошагового проведения тестирования.
6. Протестировать работоспособность системы и оформить техническую документацию.


## Что было изучено
В ходе работы над проектом я углубил свои знания в следующих областях:
- **Реляционные базы данных:** понятия таблицы, первичного ключа, внешних ключей и нормализации данных.
- **Язык SQL:** операторы определения данных (`CREATE TABLE`) и манипулирования данными (`INSERT`, `SELECT`, `UPDATE`, `DELETE`), а также использование `JOIN` для связывания таблиц.
- **Модуль `sqlite3` в Python:** подключение к базе данных, выполнение запросов, использование параметризованных запросов для защиты от SQL-инъекций.
- **Объектно-ориентированное программирование (ООП):** создание классов-моделей (`Student`, `Theme`, `Question`, `Answer`) для удобного и безопасного представления данных в коде.
- **Принципы чистой архитектуры:** разделение кода на логические модули для улучшения читаемости, тестируемости и поддержки.


## Что получилось реализовать
На данный момент проект представляет собой полностью рабочее консольное приложение со следующим функционалом:
1. **Структурированное хранение данных:** База данных содержит информацию об учащихся, учебных темах, вопросах и вариантах ответов.
2. **Интерактивное проведение теста:**
   - Программа выводит список доступных учеников и запрашивает выбор конкретного учащегося по ID.
   - Отображает список доступных тем для тестирования.
   - После выбора темы загружаются соответствующие вопросы.
   - Для каждого вопроса выводятся варианты ответов.
   - Программа принимает выбор пользователя и проверяет его на корректность с помощью метода `check_answer()`, мгновенно выводя результат («Верно» или «Неверно!»).
3. **Модульность:** Код разделен на логические части, что соответствует современным стандартам разработки и облегчает его дальнейшую доработку.

## Как запустить проект
1. Убедитесь, что на компьютере установлен Python версии 3.8 или выше.
2. Клонируйте репозиторий на свой компьютер
```bash
   git clone https://github.com/herobrinevlg-art/sqlite-python-learning.git
   cd sqlite-python-learning
```
3. Создайте и активируйте виртуальное окружение (для изоляции зависимостей проекта):
```bash
python3 -m venv .venv
.venv\Scripts\activate
```
4. Установите необходимую внешнюю библиотеку `pydantic`:
```bash
pip install pydantic
```
5. Запустите главный файл приложения:
```bash
python main.py
```
6. Следуйте инструкциям в консоли: выберите ID ученика, затем ID темы, ознакомьтесь с вопросами и выберите ID варианта ответа. Программа автоматически проверит его корректность.
